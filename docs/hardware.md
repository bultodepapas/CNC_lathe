### HBS86H Driver Technical Specifications

- Input voltage: **24–60 VDC**
- Maximum peak current: **5 A**
- Logic input current: **7–16 mA**
- Maximum pulse frequency: **200 kHz**
- Control interface: **Step / Direction**
- Encoder feedback support

Driver dimensions:

- Height: **151 mm**
- Width: **107 mm**
- Depth: **29 mm**


### Stepper Motor Technical Specifications

- Motor type: **Hybrid closed‑loop stepper**
- Frame size: **NEMA 34**
- Holding torque: **12 Nm**
- Step angle: **1.8°**
- Phase number: **2**
- Rated current: **6 A**
- Shaft diameter: **14 mm**
- Phase resistance: **0.45 Ω**
- Phase inductance: **5.2 mH**
- Insulation class: **Class B**
- Insulation resistance: **100 MΩ @ 500 VDC**
- Rotor inertia: **4.9 kg·cm²**
- Motor weight: **5 kg**
